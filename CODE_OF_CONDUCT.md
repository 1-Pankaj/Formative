# Code of Conduct

Formative welcomes contributions from people with different backgrounds and levels of experience. Keep discussions respectful, specific, and focused on the work.

Unacceptable behavior includes harassment, discrimination, personal attacks, sharing another person's private information, and deliberately disrupting project discussions.

Maintainers may edit or remove contributions that violate this standard and may restrict participation when needed. To report a concern, contact the repository maintainer privately through their GitHub profile rather than posting personal details in a public issue.
