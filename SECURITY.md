# Security policy

Formative is in active development. Until a release is marked supported, security fixes are handled on a best-effort basis.

## Reporting a vulnerability

Please do not post exploitable vulnerabilities, credentials, private transcripts, or sensitive project data in a public issue.

If private vulnerability reporting is enabled for the repository, use **Security → Report a vulnerability** on GitHub. Otherwise, contact the repository maintainer privately through their GitHub profile and include the affected version or commit, the impact, and steps to reproduce using a safe example. Do not include real user data or working secrets.

The maintainer will acknowledge the report when possible and coordinate disclosure after a fix or mitigation is available. Please allow time for investigation before making a vulnerability public.
